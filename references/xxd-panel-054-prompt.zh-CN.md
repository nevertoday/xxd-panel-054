# XXD Panel 054｜选择性记忆贴纸册生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

只处理当前新任务明确提供的这一张源照片。私下锁定主体身份、剪影、比例、姿态、动作、叙事关系、综合色温与具有记忆价值的局部，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

不要完整描摹照片。把复杂场景压缩成三至六个大块面，建立一个承担主要叙事的主视觉，再从原照片选择恰好六个真正有记忆价值的局部，转化为六枚主次分明、大小不同的贴纸。所有元素共享哑光水粉、剪纸、Risograph或丝网印刷式材料语言，形成安静、现代、松弛的独立出版视觉记忆册。

严格遵循这条因果链：锁定身份、剪影、姿态与叙事关系 → 保留三个识别线索 → 将复杂内容压缩为三至六个大块面 → 建立一个一眼可认的主视觉 → 选择恰好六个源图记忆碎片 → 变化贴纸尺度、角度、遮挡与主次 → 用统一的哑光水粉与印刷质感整合 → 保留空气感蓝色系留白 → 把极少文案放入剩余节奏。

## 硬性视觉要求

- 从剪影、比例、姿态、动作、局部结构、色彩、材质或关系中保留至少三个源图专属线索；将场景简化为三至六个哑光大块面但维持瞬间可识别性。
- 建立一个明显最大的主视觉。再从主体特征、动作、结构、植物、器物、交通、食物、纹样、材质、光影或偶然细节中选择恰好六个有源图依据的记忆碎片，为每枚贴纸加厚实浅色切边。
- 六枚贴纸必须大小、主次与视觉重量不同；以松散两排、边缘聚集或围绕主视觉的非对称关系组织，可轻微旋转、遮挡或越界。不得变成商品目录、六宫格或等尺寸图标组。
- 主视觉和贴纸共享不透明水粉、剪纸、Risograph或丝网印刷材料：粉质边缘、纸张颗粒、手工切边与轻微套印偏差。拒绝水彩晕染、密集线稿、写实纹理、光滑矢量和3D塑料。
- 以浅粉蓝、雾蓝、天空蓝与空气感冷蓝建立主氛围，以象牙白、奶油白、浅米色、柔和灰绿与建筑中性色平衡；只有源图支持时，允许极少 dusty rose 或 muted blush 点缀。
- 通过尺度反差、正负形、前后遮挡与大面积安静底色控制一个主焦点；六枚贴纸不得争夺主视觉。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。只从主体、动作、环境、情绪、声音、记忆或文化语境提炼一个词、短句或极短标题，放入留白、贴纸间隙或主视觉边缘。文字必须小、轻、克制并具有编辑关系；不得逐一标注贴纸或建立信息栏。用户准确文案逐字保留；无文字模式不得出现字母、字符、数字、标签或伪文字。

## 模式与验收


拒绝：贴纸商品目录、六宫格、等尺寸排列、完整写实风景、密集细节、商业明信片模板、水彩晕染、复杂笔触、密集线稿、光滑矢量、3D塑料、卡通、动漫与电商素材。同时拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语和不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
